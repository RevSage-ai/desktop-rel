# RevSage Desktop: downloads

Windows installers for the RevSage desktop app. This repository holds releases only. It contains no source code.

## Download

1. Open the [latest release](../../releases/latest).
2. Under **Assets**, download the file ending in `-setup.exe`.
3. Run it and follow the installer.

Requirements: Windows 10 or 11 (64-bit).

## "Windows protected your PC"

The installer is not yet code-signed, so Windows SmartScreen may warn about an unknown publisher. If you downloaded it from this page, choose **More info**, then **Run anyway**.
